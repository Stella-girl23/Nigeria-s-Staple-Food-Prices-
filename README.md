# Nigeria-s-Staple-Food-Prices-
Analysis of monthly staple food prices across 36 states and the FCT, Dec 2024 to Jun 2025, using Python and Power BI

This project analyses monthly average prices for 10 staple foods across Nigeria, using crowdsourced price data curated by the National Bureau of Statistics and distributed through the World Bank Microdata Library. It covers the imported rice premium, state-level price variation, and the change in prices between December 2024 and June 2025.
